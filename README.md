# Rummy V1

A simple local Flutter prototype for the points-only Rummy game.

## Included
- 52-card deck and 13-card starting hand
- Draw / discard
- 30-second turn + 5-second grace period (35 seconds total)
- Automatic discard on timeout
- Player names and points panel
- Discard history visible; picked cards are not exposed
- Basic declare button
- No real-money features

## Run
1. Install Flutter.
2. Create/open this project.
3. Run `flutter pub get`
4. Run `flutter run`

This is a prototype, not yet real-time online multiplayer.
